# Formation Terraform AWS


Ca projet démontre ma maitrise de Terraform pour deployer une infrastructure AWS complete

## Ce que ce projet contient
- Un VPC avec sous-reseaux public et privée
- Une passerelle Internet et une table de routage
- Un Security Group sécurisé (SSH restreint à mon adresse IP)
- Une instance EC2 deployant Apache automatiquement

## Technologies Utilisées 
- Terraform
- AWS
- Amazon Linux 2

## Comment Utiliser 
- 'terraform init'
- 'terraform plan'
- 'terraform apply'
- 'terraform destroy' (pour nettoyer )
